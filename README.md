# Replication Lee et al.
Repository for the term paper in the course Advanced Small Area Estimation at the University of Bamberg

The repository contains both the short and final presentation as well as the term paper itself. All data used are located in the folder "data". The file "Lee_et_al_JcAIC" contains all code provided by the author of the paper. 

Finally, the folder "R" contains all relevant scripts. Here, the different simulation scripts can be found as well as the preprocessing script.
